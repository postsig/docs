PostSig recognizes nine contract types. Each one renders a tailored set of fields in the app. Two types — **Invoice** and **NDA** — have their own custom field set; the other seven share a single default set.

## All contract types

| Contract Type | Field set | Per-type docs |
| --- | --- | --- |
| Master Services Agreement (MSA) | Default | [MSA →](/contract-types/msa) |
| Service Order (SO) | Default | [SO →](/contract-types/so) |
| Addendum | Default | [Addendum →](/contract-types/addendum) |
| Other | Default | [Other →](/contract-types/other) |
| Terms of Service (TOS) | Default | [TOS →](/contract-types/tos) |
| Invoice | **Custom** | [Invoice →](/contract-types/invoice) |
| Trial Agreement | Default | [Trial →](/contract-types/trial) |
| NDA | **Custom** | [NDA →](/contract-types/nda) |
| Operational Agreement | Default | [Operational →](/contract-types/operational) |

For full definitions of every field, see the [Contract Fields glossary](/fields).
