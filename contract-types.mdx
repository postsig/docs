PostSig recognizes nine contract types. Each one renders a tailored set of fields in the app, organized into overview, contract-details, and metadata zones. Two types — **Invoice** and **NDA** — use custom field configurations; the other seven share a single default configuration.

## Storage vs. display

A contract row stores the numeric foreign key `type_id` (1–9). The UI and exports display the resolved name from the `contract_types` table as `contract_type` (e.g. `"MSA"`). When working with the API or raw data, refer to `type_id`; when reading user-facing surfaces, refer to `contract_type`.

## What changes per type

Each per-type page documents:

- **Overview** — fields shown at the top of the contract view
- **Contract Details** — sectioned field groups shown below
- **PostSig Metadata** — extraction-time metadata (notes, summary, asset classes, tags, missing fields; NDA also includes risk indicators)
- **Tabs** — which side panels are available (Owner, DORA, Audit, Lineage)
- **Baseline** — fields that appear on every contract regardless of type

For full definitions of every field, see the [Contract Fields glossary](/fields).
