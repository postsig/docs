<Info>
  **Type ID:** `6`    **Field configuration:** Custom (Invoice-specific)
</Info>

Invoice contracts use a narrowed field configuration focused on the financial details of a single billing event. Renewal, multi-year, and most negotiated terms are intentionally omitted.

## Overview

Top-of-page fields. Invoices include the execution date, billing frequency, and currency in the overview itself — fields that live in deeper sections for other contract types.

| Field | Description |
| --- | --- |
| [`term_start_date`](/fields#date-fields) | The calendar date on which the term begins |
| [`term_end_date`](/fields#date-fields) | The calendar date on which the term ends |
| [`execution_date`](/fields#date-fields) | The date the document was signed |
| [`billing_frequency`](/fields#payment) | How often the client is billed |
| [`subscription_term`](/fields#date-fields) | Length of the term, in months |
| [`currency`](/fields#payment) | Currency the amounts are expressed in |

## Contract details

### Products Licensed

| Field | Description |
| --- | --- |
| [`products_licensed`](/fields#products-licensed) | Products covered by this invoice |

### Product terms

| Field | Description |
| --- | --- |
| [`market_data_types`](/fields#permissions--scope-of-use) | Real-time/delayed quotes, fixed income holdings, T&C, historical data |
| [`data_delivery_types`](/fields#permissions--scope-of-use) | Delivery methods such as SFTP or Snowflake |

### Payment details

| Field | Description |
| --- | --- |
| [`payment_terms`](/fields#payment) | Detail on how the client must pay |
| [`renewal_period`](/fields#payment) | The term covered by any renewal |
| [`cancellation_process`](/fields#payment) | How to cancel before auto-renewal |

### Permissions and scope of use

| Field | Description |
| --- | --- |
| [`end_users`](/fields#permissions--scope-of-use) | Detail about users, groups, locations, tiered pricing |
| [`number_of_users`](/fields#permissions--scope-of-use) | Licensed user allocations per product |

<Note>
  Invoices intentionally **omit** the Adjustments, Marketing Rights, SLA, Audit, Arbitration, Security Awareness, and other long-form term sections that appear on the default field set. They are billing artifacts, not negotiated agreements.
</Note>
